## รายละเอียดเนื้อหาและปฏิบัติการ

### Week 01: Introduction to Embedded Systems & ESP32-S3
* **ความรู้และประเด็นสำคัญ:**
  * ทำความเข้าใจบทบาทและข้อจำกัดของระบบสมองกลฝังตัว (Embedded Systems) เช่น ข้อจำกัดด้านหน่วยความจำ พลังงาน และการตอบสนองแบบเวลาจริง (Real-Time)
  * ศึกษาคุณสมบัติเด่นของชิป **ESP32-S3** ซึ่งใช้หน่วยประมวลผล **Xtensa® 32-bit LX7 Dual-Core** ความเร็วสูงสุด 240 MHz รองรับคำสั่งประมวลผลเชิงเวกเตอร์ (AI/DSP acceleration) และการเชื่อมต่อไร้สาย Wi-Fi (2.4 GHz) ร่วมกับ Bluetooth 5 (LE)
  * เปรียบเทียบแนวทางการพัฒนาซอฟต์แวร์ระหว่าง Arduino Framework กับ **ESP-IDF (Espressif IoT Development Framework)** ซึ่งเป็น SDK ทางการที่ให้ความยืดหยุ่นและประสิทธิภาพสูงกว่า
* **สิ่งที่ได้ลงมือปฏิบัติ:**
  * วิเคราะห์สเปกของชิป ESP32-S3 จาก Datasheet และวางแผนโครงสร้างการเรียนรู้สำหรับงานพัฒนา IoT และระบบแสดงผลกราฟิก

### Week 02: ES3C28P Hardware Architecture
* **ความรู้และประเด็นสำคัญ:**
  * ศึกษาโครงสร้างฮาร์ดแวร์ของบอร์ด **ES3C28P** ซึ่งใช้โมดูล **ESP32-S3R8** เป็นหน่วยประมวลผลหลัก
  * ทำความเข้าใจการสื่อสารระหว่าง MCU กับอุปกรณ์ต่อพ่วงบนบอร์ดผ่านบัสมาตรฐานต่าง ๆ ได้แก่ SPI, I2C, I2S และ SDIO
  * ศึกษาระบบจัดการพลังงาน (5V จากพอร์ต USB Type-C แปลงเป็น 3.3V ผ่าน LDO Regulator และวงจรชาร์จแบตเตอรี่ลิเธียม 3.7V)
* **สรุปผังขาอุปกรณ์ต่อพ่วงสำคัญบนบอร์ด ES3C28P:**

| อุปกรณ์ต่อพ่วง | ชิปควบคุม / รุ่น | อินเทอร์เฟซ | ขาเชื่อมต่อ (GPIO) |
| :--- | :--- | :--- | :--- |
| **หน้าจอแสดงผล (2.8" IPS)** | ILI9341V (240x320) | 4-Wire SPI | `CS: IO10`, `DC: IO46`, `SCK: IO12`, `MOSI: IO11`, `MISO: IO13`, `BL: IO45` |
| **หน้าจอสัมผัส (Capacitive)** | FT6336G (`0x38`) | I2C | `SDA: IO16`, `SCL: IO15`, `INT: IO17`, `RST: IO18` |
| **หลอดไฟสถานะ RGB LED** | WS2812 (Single-wire) | Digital IO | `DATA: IO42` |
| **ช่องเสียบ MicroSD Card** | SDIO 4-bit Mode | SDIO | `CLK: IO38`, `CMD: IO40`, `D0-D3: IO39, IO41, IO48, IO47` |
| **ระบบเสียง (Audio Codec)** | ES8311 (`0x18`) | I2C / I2S | `EN: IO1`, `MCK: IO4`, `SCK: IO5`, `DO: IO6`, `LRC: IO7`, `DI: IO8` |
| **ปุ่มกดผู้ใช้ (BOOT Key)** | Tactile Switch | Digital Input | `BOOT: IO0` (Active Low) |

* **สิ่งที่ได้ลงมือปฏิบัติ:**
  * อ่านวงจร (Schematic) และตรวจสอบตาราง Pinout ของบอร์ด ES3C28P เพื่อป้องกันการใช้ขา GPIO ชนกับอุปกรณ์ออนบอร์ด

### Week 03: ESP-IDF Setup and ESP32-S3 Hello World
* **ความรู้และประเด็นสำคัญ:**
  * เข้าใจองค์ประกอบของเครื่องมือพัฒนาใน ESP-IDF ได้แก่ Compiler (`xtensa-esp32s3-elf-gcc`), ระบบ Build (`CMake` และ `Ninja`) และเครื่องมือบริหารจัดการโปรเจกต์ (`idf.py`)
  * ศึกษาโครงสร้างไฟล์มาตรฐานของโปรเจกต์ ESP-IDF:
    * `CMakeLists.txt` (ระดับ Root และระดับ Component) สำหรับกำหนดค่าการคอมไพล์
    * `sdkconfig` สำหรับเก็บค่าคอนฟิกของระบบที่ตั้งค่าผ่าน `menuconfig`
    * `main/app_main.c` ซึ่งเป็นจุดเริ่มต้นการทำงานหลักของแอปพลิเคชัน
* **สิ่งที่ได้ลงมือปฏิบัติ:**
  * ติดตั้ง ESP-IDF และส่วนขยายบน Visual Studio Code พร้อมทดสอบการเชื่อมต่อบอร์ดผ่านพอร์ต USB Type-C
  * สร้างและรันโปรเจกต์ `hello_world` ด้วยลำดับคำสั่งพื้นฐาน:
    1. `idf.py set-target esp32s3` (กำหนดเป้าหมายชิป)
    2. `idf.py menuconfig` (ตรวจสอบการตั้งค่า Flash และ PSRAM)
    3. `idf.py build` (คอมไพล์ซอร์สโค้ดเป็นไฟล์ไบนารี)
    4. `idf.py -p <PORT> flash monitor` (อัปโหลดโปรแกรมและเปิดดูผลลัพธ์ผ่าน Serial Monitor)
  * ทดลองแก้ไขโค้ดใน `app_main()` เพื่อแสดงข้อมูลสเปกชิป จำนวน Core และขนาดหน่วยความจำออกทางหน้าจอ Terminal

### Week 04: Memory Architecture & Basic GPIO Control
* **ความรู้และประเด็นสำคัญ:**
  * ศึกษาโครงสร้างหน่วยความจำของชิป ESP32-S3R8 และบอร์ด ES3C28P แบ่งออกเป็น 2 ส่วนหลัก:
    1. **Internal Memory (ภายในชิป):**
       * **ROM (384 KB):** เก็บ Bootloader ระดับแรกและฟังก์ชันพื้นฐานของระบบ
       * **SRAM (512 KB):** แบ่งใช้งานเป็น **IRAM** (Instruction RAM สำหรับเก็บโค้ดที่ต้องการความเร็วสูงหรือ Interrupt) และ **DRAM** (Data RAM สำหรับตัวแปรและ Stack)
       * **RTC SRAM (16 KB):** หน่วยความจำพลังงานต่ำที่ยังคงรักษาข้อมูลไว้ได้แม้เข้าสู่โหมด Deep-sleep
    2. **External Memory (ภายนอกชิป):**
       * **QSPI Flash (16 MB):** เก็บเฟิร์มแวร์ ระบบไฟล์ และตารางแบ่งส่วนข้อมูล (**Partition Table**)
       * **OPI PSRAM (8 MB):** หน่วยความจำชั่วคราวส่วนขยายความเร็วสูง สำหรับพักข้อมูลขนาดใหญ่ เช่น Framebuffer ของหน้าจอ LCD หรือข้อมูลเสียง
  * เข้าใจหลักการกำหนดค่าและใช้งาน **GPIO** ผ่านไดรเวอร์ `driver/gpio.h` (การตั้งค่า Direction, Pull-up/Pull-down และการอ่าน/เขียนลอจิก)
* **สิ่งที่ได้ลงมือปฏิบัติ:**
  * ตรวจสอบตาราง Partition Table และขนาดหน่วยความจำ Heap/PSRAM ที่เหลือใช้งานจริงขณะรันโปรแกรม
  * ทดลองเขียนโปรแกรมควบคุมเอาต์พุตดิจิทัล (เช่น การสั่งเปิด/ปิด Backlight หน้าจอที่ขา `IO45` และการส่งสัญญาณควบคุม `WS2812 RGB LED` ที่ขา `IO42`) ร่วมกับการรับค่าอินพุตจากปุ่มกด `BOOT` (`IO0`)

### Week 05: FreeRTOS Fundamentals & Multitasking
* **ความรู้และประเด็นสำคัญ:**
  * ทำความเข้าใจการทำงานของ **FreeRTOS** ที่ถูกฝังมาเป็นแกนหลักของ ESP-IDF และรองรับการทำงานแบบ **SMP (Symmetric Multiprocessing)** บนซีพียู 2 คอร์ (Core 0 และ Core 1)
  * ศึกษาวงจรชีวิตและสถานะของ **Task** (`Running`, `Ready`, `Blocked`, `Suspended`) รวมถึงการจัดลำดับความสำคัญ (**Priority**)
  * เข้าใจความแตกต่างของการหน่วงเวลาแบบ Blocking ด้วย `vTaskDelay()` (คืนทรัพยากร CPU ให้ Task อื่นทำงานต่อได้) เทียบกับการวนลูปรอแบบดั้งเดิม
  * ศึกษาการส่งข้อมูลและการป้องกันการแย่งใช้ทรัพยากรร่วมกันระหว่าง Task ด้วย **Queue**, **Binary Semaphore** และ **Mutex**
* **สิ่งที่ได้ลงมือปฏิบัติ:**
  * ทดลองสร้างหลาย Task ทำงานพร้อมกันด้วย `xTaskCreate()` และระบุคอร์ประมวลผลด้วย `xTaskCreatePinnedToCore()` เช่น แยก Task สำหรับควบคุมไฟกะพริบ RGB LED ออกจาก Task สำหรับอ่านค่าปุ่มกดและส่งข้อความรายงานสถานะ
  * ทดลองใช้ **Queue** เพื่อส่งคำสั่งหรือสถานะจาก Task รับอินพุตไปยัง Task แสดงผลได้อย่างปลอดภัยและไม่เกิดการขัดจังหวะของข้อมูล
